# DinaPlayer — гайд для дизайнера (macOS / любой ОС)

Привет! Ты правишь внешний вид плеера. Хорошая новость: **сам интерфейс кроссплатформенный**,
поэтому тебе не нужен Windows, чтобы менять дизайн и видеть результат вживую.

DinaPlayer = [mpv](https://mpv.io) + скин [**uosc**](https://github.com/tomasklaen/uosc) +
несколько конфигов. Финальный `.exe` под Windows собирает Dina; **ты работаешь с
конфигами/Lua/ассетами**, которые одинаковы на всех ОС.

---

## 1. Быстрый старт на Mac

```bash
# 1. Установить mpv (он умеет читать uosc-скин из нашего конфига)
brew install mpv

# 2. Склонировать репозиторий (или через Claude)
git clone https://github.com/sha-ridi/dina-player.git
cd dina-player

# 3. Запустить mpv с НАШИМ конфигом — это и есть наш интерфейс
mpv --config-dir="$PWD/portable_config" ~/путь/к/любому/видео.mp4
```

Флаг `--config-dir` заставляет mpv взять именно наши `mpv.conf`, `input.conf`, скин uosc,
превью-миниатюры и т.д. То, что ты видишь этой командой на маке, — ровно то, что увидит
пользователь на Windows.

> Удобно: сделай себе алиас, чтобы не печатать путь каждый раз:
> ```bash
> alias dina='mpv --config-dir="/полный/путь/к/dina-player/portable_config"'
> # потом просто: dina video.mp4
> ```

**Цикл работы:** правишь файл → перезапускаешь mpv этой командой → сразу видишь изменение
→ доволен → `git commit` + `git push`. Dina забирает и собирает Windows-билд.

## 2. Где что менять

Всё живёт в папке `portable_config/`.

| Что хочешь изменить | Файл |
| --- | --- |
| **Внешний вид панели/кнопок/таймлайна (главное)** | `portable_config/script-opts/uosc.conf` |
| Логика/вёрстка элементов скина (глубокие правки) | `portable_config/scripts/uosc/` (Lua) |
| Превью-миниатюры при наведении | `portable_config/script-opts/thumbfast.conf` |
| Горячие клавиши | `portable_config/input.conf` |
| Базовые настройки видео/звука | `portable_config/mpv.conf` |
| **Иконка приложения** (Windows) | `assets/dinaplayer.ico` |

Иконки на панели — из набора **Material Icons Round** (шрифт
`portable_config/fonts/uosc_icons.otf`). Чтобы поменять иконку кнопки, укажи в
`controls=` (в `uosc.conf`) другое имя из [fonts.google.com/icons](https://fonts.google.com/icons)
(стиль «Rounded») — отдельный шрифт собирать не нужно.

### Главный файл — `script-opts/uosc.conf`

Это **основной инструмент дизайна**. Мы завендорили полный дефолтный `uosc.conf`, в котором
**каждая опция снабжена комментарием-описанием** — просто открой и правь по месту. Там
настраивается:

- **цвета** (передний план, фон, текст, «шторка» затемнения);
- **размеры и поведение таймлайна** (высота, толщина, чаптеры);
- **набор и порядок кнопок** на нижней панели и в топ-баре;
- **шрифт, масштаб текста, скругления углов, прозрачность**.

Полный справочник по темизации и синтаксису опций — в
[README uosc](https://github.com/tomasklaen/uosc#configuration) и в
[гайде по кастомизации](https://github.com/tomasklaen/uosc/blob/main/src/uosc.conf).

> ⚠️ В самом конце `uosc.conf` есть блок `# --- DinaPlayer overrides ---` — это наши
> правки поверх дефолта. Свои дизайнерские настройки лучше добавлять/менять там, чтобы
> было видно, что именно мы поменяли относительно стандартного uosc.

**Размер интерфейса в фуллскрине.** В стандартном uosc размеры элементов одни и те же
в окне и в фуллскрине (глобальный множитель `scale_fullscreen` растягивает вообще всё, включая
пропорции). Мы добавили свои опции с суффиксом `_fullscreen` — они действуют **только**
в фуллскрине/развёрнутом окне, `0` = взять обычное значение:

| Опция | Что увеличивает |
| --- | --- |
| `controls_size_fullscreen` | иконки нижней панели |
| `top_bar_size_fullscreen` | верхняя панель и заголовок |
| `timeline_size_fullscreen` | таймлайн и таймкоды |
| `menu_item_height_fullscreen` | высота строки меню — от неё считаются размер текста и отступы |
| `menu_min_width_fullscreen` | минимальная ширина окна меню |
| `menu_padding_fullscreen` | внутренние поля меню |
| `skip_ending_size_fullscreen` | плашка «Следующая серия» целиком |

Реализация: функция `fullscreen_size()` в `scripts/uosc/main.lua`, её вызывают
`Controls.lua`, `TopBar.lua`, `Timeline.lua`, `Menu.lua` и `SkipEnding.lua`.
Так в фуллскрине интерфейс крупный (как в Netflix), а в окне остаётся компактным.

Ещё две наши опции — уже не про фуллскрин, а про времена в углах таймлайна:
`timeline_timestamp_scale` (множитель кегля поверх того, что uosc считает от высоты
полосы) и `timeline_timestamp_border` (обводка текста в пикселях, `0` — без обводки).

## 3. Нюанс macOS: `ziggy`

При сборке Windows-дистрибутива мы удаляем не-Windows бинарники uosc, поэтому в репозитории
лежит только `portable_config/scripts/uosc/bin/ziggy-windows.exe`.

Для **чисто визуального превью** на маке это не мешает — таймлайн, кнопки, меню и
превью-миниатюры рисуются без ziggy. Но если тебе понадобятся функции uosc, которые его
используют (загрузка субтитров, автообновление, часть операций с файлами), доставь себе
локально `ziggy-darwin`:

```bash
# один раз, локально — НЕ коммить этот файл
curl -L -o portable_config/scripts/uosc/bin/ziggy-darwin \
  https://github.com/tomasklaen/uosc/releases/latest/download/ziggy-darwin
chmod +x portable_config/scripts/uosc/bin/ziggy-darwin
```

`ziggy-darwin` уже в `.gitignore`? Нет — просто не добавляй его в коммит (`git add` только
изменённые конфиги/Lua). Он нужен лишь тебе локально; на Windows-сборке своя версия.

## 4. Иконка приложения

`assets/dinaplayer.ico` — текущая иконка приложения. Формат `.ico` виндовый, но
рисовать можно в чём угодно (Figma, Sketch, PNG). Если понадобится обновить арт —
пришли квадрат 256×256 и/или 512×512 (PNG с прозрачностью), Dina сконвертирует в
`.ico` и пересоберёт. Конвертировать `.ico` самому не обязательно.

---

## 5. Что НЕ получится на маке (и это нормально)

- Запустить готовый `DinaPlayer.exe` — это Windows-бинарник.
- Запустить сборочные скрипты (`build/*.ps1`, `install/*.bat`) — они под Windows.
- Собрать финальный ZIP-дистрибутив — это делает Dina на Windows.

Тебе это и не нужно: ты меняешь дизайн, проверяешь его через `mpv --config-dir=...`,
коммитишь — а сборку и проверку на Windows берёт на себя Dina.

```bash

```
