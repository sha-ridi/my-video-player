# DinaPlayer — дизайн-спецификация

**Дата:** 2026-07-16
**Статус:** одобрено, готово к планированию реализации

## 1. Цель и суть

Персональный видеоплеер для Windows с удобным, быстрым, не лагающим интерфейсом
в стиле YouTube. Мы **не пишем плеер с нуля**, а берём самое быстрое всеядное
ядро ([mpv](https://mpv.io/)) и превращаем его в удобный YouTube-подобный плеер
через конфигурацию, готовые опенсорс-скрипты и лёгкую кастомизацию под бренд
DinaPlayer.

Ключевые приоритеты (в порядке важности):
1. Простота и скорость реализации, нативная производительность, ноль лагов.
2. Удобство управления в стиле YouTube (перемотка, пауза, дорожки).
3. Корректная работа с сериалами (порядок, авто-переход, память позиции).

## 2. Область (scope)

**Контент:** только локальные файлы (mkv, mp4, avi и прочие форматы mpv).

**Дистрибуция:** самодостаточная **портативная папка в ZIP** (`DinaPlayer-Portable.zip`)
с вложенным mpv — переносится на любой компьютер с Windows копированием, без прав
администратора. Плеер запускается как `DinaPlayer.exe`.

**Осознанно НЕ делаем (YAGNI):**
- ❌ Экран библиотеки/постеров (Netflix-стиль) — выбран YouTube-стиль.
- ❌ Онлайн-сервисы, стриминг по сети, торренты.
- ❌ Собственный веб-UI (Electron/Tauri).

## 3. Архитектурный подход

Выбран **Подход A: mpv + современный скин**. DinaPlayer — это портативная
преднастроенная и отскиненная сборка mpv под собственным брендом.

Отклонённые альтернативы:
- **mpv.net (C# фронтенд)** — тот же движок, но кастомизация UI всё равно через
  mpv-скрипты; лишний слой без выгоды для наших целей.
- **Свой веб-UI поверх mpv** — полная свобода дизайна, но тяжелее, риск
  рассинхрона/лагов и много кода; противоречит выбранному приоритету «простота
  и скорость».

## 4. Компоненты

### 4.1 Ядро — mpv
Портативная папка с `mpv.exe` / `libmpv`. Аппаратное декодирование (`hwdec`),
рендер через `gpu-next`. Собственный код ядра не пишем.

Плеер запускается пользователем как **`DinaPlayer.exe`** — это `mpv.exe`,
переименованный и с нашей иконкой.

Бинарник mpv **не хранится в репозитории** (чтобы репозиторий оставался чистым),
но **вкладывается в релизный ZIP** скриптом сборки. Так дистрибутив
самодостаточен: работает офлайн и переносится на любой компьютер копированием
папки.

### 4.2 `portable_config/` — сердце проекта

- **`mpv.conf`** — воспроизведение и поведение:
  - `hwdec=auto-safe` — аппаратное декодирование без риска артефактов.
  - `vo=gpu-next` — современный видеовыход.
  - `save-position-on-quit=yes` — запоминание позиции и дорожек по каждому файлу.
  - `keep-open=yes` — корректное поведение в конце файла / авто-переход в плейлисте.
  - `alang`/`slang` — языковые предпочтения аудио и субтитров (например, jpn + rus),
    применяются ко всему сериалу как значения по умолчанию.
- **`input.conf`** — горячие клавиши в стиле YouTube:
  - `←/→` — перемотка (напр. ±5 c), `Shift+←/→` — крупный шаг.
  - `Space` / клик по видео — пауза.
  - `↑/↓` — громкость.
  - `F` — полноэкранный режим, `M` — mute и т.д.
- **`scripts/`** — готовые опенсорс-скрипты:
  - **uosc** — современный UI: большая полоса перемотки, аккуратные кнопки,
    меню субтитров / аудио / плейлиста.
  - **thumbfast** — превью-миниатюры при наведении на полосу перемотки.
  - **autoload (natural sort)** — авто-построение плейлиста из папки в
    натуральном порядке (Episode 2 раньше Episode 10, а не 1, 10, 2).
- **`script-opts/`** — `uosc.conf` (наша YouTube-тема: цвета, шрифты, скругления)
  и `thumbfast.conf`.
- **`fonts/`** — бандл шрифта для единообразного вида UI.

### 4.3 `install/` — интеграция с Windows (внутри дистрибутива)
Скрипты, которые лежат **внутри готовой папки DinaPlayer** и запускаются на
целевом компьютере. Всё пишется в **HKCU (без прав администратора)**, пути
указывают на текущее расположение папки, поэтому её можно распаковать куда угодно.

`setup.bat` добавляет **только контекстные меню** (пункты 2 и 3), но
**НЕ делает плеер по умолчанию** — ассоциации файлов пользователь при желании
ставит сам средствами Windows.

- **`setup.bat`** (обёртка над PowerShell) — запускается один раз после распаковки:
  - Пункт **«Открыть с помощью DinaPlayer»** в контекстном меню видеофайлов.
  - Пункт **«Play with DinaPlayer»** в контекстном меню папок (запуск через
    маленький враппер, который находит первый видеофайл; остальное достроит
    autoload).
- **`uninstall.bat`** — удаляет добавленные пункты меню из HKCU.
- Плеером можно пользоваться и **без `setup.bat`** — просто запуская
  `DinaPlayer.exe` и перетаскивая файлы (portable-режим).
- Сделать плеером по умолчанию (двойной клик) — вручную: правый клик по видео →
  «Открыть с помощью» → «Выбрать другое приложение» → `DinaPlayer.exe` →
  «Всегда». Инструкция дублируется в README.

### 4.4 `build/` — сборка релиза (на машине разработки)
- **`build-release.ps1`** — собирает самодостаточный дистрибутив:
  1. Скачивает свежую сборку mpv для Windows.
  2. Раскладывает `portable_config`, `assets`, `install`-скрипты.
  3. Переименовывает `mpv.exe` → `DinaPlayer.exe` и подставляет иконку.
  4. Пакует всё в `DinaPlayer-Portable.zip` — единственный артефакт для переноса.

### 4.5 `assets/`
Иконка `dinaplayer.ico`, брендинг (имя окна, отображаемое имя в ассоциациях).

## 5. Маппинг фич на решения

| Требование | Решение |
|---|---|
| Удобная перемотка | uosc-полоса + thumbfast превью + хоткеи `←/→` |
| Пауза | `Space` / клик по видео |
| Смена субтитров / аудио | Меню uosc + хоткеи; выбор запоминается |
| Правильный порядок серий | autoload с натуральной сортировкой |
| Авто-переход к следующей серии | `keep-open` + автоплейлист |
| Запоминание позиции | `save-position-on-quit` (позиция + дорожки на файл) |
| На какой серии остановились | watch-later хранит позицию для каждого файла папки |
| Память аудио / субтитров | `alang`/`slang` для сериала + per-file в watch-later |
| Запуск: двойной клик | Вручную через Windows «по умолчанию» (не через setup.bat) |
| Запуск: «Открыть с помощью DinaPlayer» | Контекстное меню файла (setup.bat, HKCU) |
| Запуск: папка целиком | Контекстное меню папки → враппер → mpv + autoload (setup.bat) |
| Запуск: drag & drop | Нативная поддержка mpv (бонусом) |

## 6. Поток данных

Запуск видео (через «Открыть с помощью DinaPlayer», двойной клик при вручную
выставленной ассоциации, или drag & drop) → Windows запускает `DinaPlayer.exe` с
путём к файлу → загружается `portable_config` → autoload строит плейлист папки в правильном
порядке → uosc рисует UI, thumbfast готовит превью → watch-later восстанавливает
позицию и выбранные дорожки → при выходе позиция сохраняется.

## 7. Структура репозитория и дистрибутива

### 7.1 Репозиторий (что редактируем и храним в git)
```
DinaPlayer/
├─ portable_config/
│  ├─ mpv.conf
│  ├─ input.conf
│  ├─ fonts/
│  ├─ scripts/        (uosc, thumbfast, autoload-natural, custom.lua при необходимости)
│  └─ script-opts/    (uosc.conf, thumbfast.conf)
├─ install/           (setup.bat, uninstall.bat + вспомогательные .ps1)
├─ build/             (build-release.ps1)
├─ assets/            (dinaplayer.ico)
├─ docs/              (спецификации и планы)
└─ README.md
```
Бинарник mpv в git **не хранится** (см. 4.1).

### 7.2 Готовый дистрибутив `DinaPlayer-Portable.zip` (что переносим на другой ПК)
```
DinaPlayer/
├─ DinaPlayer.exe        (mpv.exe с нашей иконкой)
├─ *.dll                 (зависимости mpv)
├─ portable_config/      (наши конфиги и скрипты)
├─ setup.bat             (контекстные меню файла и папки, запуск 1 раз, без админа)
├─ uninstall.bat
└─ README.txt
```
Использование на новом компьютере: распаковать ZIP куда угодно → (по желанию)
запустить `setup.bat` для контекстных меню «Открыть с помощью / Play with
DinaPlayer». Плеером по умолчанию — вручную при желании. Без setup.bat работает
как portable-плеер.

## 8. Обработка ошибок

- Нет сборки mpv при сборке релиза → `build-release.ps1` прерывается с понятной
  ошибкой (докачивает mpv на этапе сборки, а не у пользователя).
- Битый / неподдерживаемый файл → mpv показывает ошибку в OSD; `keep-open`
  предотвращает «вылет».
- Отсутствует скрипт / шрифт → фиксируется в логе mpv; `build-release.ps1`
  проверяет наличие обязательных файлов перед упаковкой ZIP.
- `setup.bat` запущен из временной папки распаковки → предупреждаем в README,
  что папку сначала нужно распаковать в постоянное место (пути в реестре
  указывают на текущее расположение).

## 9. Проверка (verification)

Ручной чек-лист приёмки:
1. Воспроизведение одиночного файла.
2. Перемотка с превью-миниатюрами.
3. Пауза по `Space` и по клику.
4. Смена аудио-дорожки и субтитров через меню.
5. Открытие папки → плейлист в натуральном порядке.
6. Авто-переход к следующей серии в конце текущей.
7. Выход и повторное открытие → продолжение с той же позиции и с теми же дорожками.

Дополнительно: мини-проверка `mpv --idle` для sanity-check конфигов и загрузки
скриптов без ошибок.
