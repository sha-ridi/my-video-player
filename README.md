# DinaPlayer

Быстрый персональный видеоплеер для Windows в стиле YouTube на базе [mpv](https://mpv.io).
Удобная перемотка с превью-миниатюрами, память позиции и дорожек, правильный порядок
серий и авто-переход к следующей.

> Публичный репозиторий: исходники, релизы и сайт DinaPlayer. Конечные пользователи ставят плеер установщиком
> `DinaPlayer-Setup.exe`; всё, что ниже, — про сборку и разработку.

## Установка (для пользователя)

Единственное действие — запустить **`DinaPlayer-Setup.exe`**. Он скачивает свежую
сборку из публичного репозитория релизов, ставит плеер и потом обновляет его
(в том числе кнопкой «Update DinaPlayer» внутри плеера). В окне установки
галочками можно добавить пункт «Play with DinaPlayer» в контекстное меню
файлов/папок, ярлык на рабочий стол и сделать DinaPlayer плеером по умолчанию.
Права администратора не нужны — всё пишется в профиль пользователя (`HKCU`);
удаление — из того же установщика.

(Портативный путь тоже работает: распаковать `DinaPlayer-Portable.zip` и запустить
`setup.bat` / `update.bat`, — но установщик основной.)

## Сборка и релиз (Windows + PowerShell)

Требуется Windows и PowerShell (подойдёт встроенный `powershell` 5.1). mpv и
вспомогательные бинарники скачиваются из сети при сборке.

```powershell
# Выпустить новую версию: собрать ZIP + установщик и опубликовать релиз на GitHub
# (основная команда после любой правки):
powershell -ExecutionPolicy Bypass -File build/publish-release.ps1

# Просто собрать дистрибутив dist/DinaPlayer-Portable.zip, без публикации:
powershell -ExecutionPolicy Bypass -File build/build-release.ps1

# Песочница для отладки конфигов (mpv + junction на portable_config):
powershell -ExecutionPolicy Bypass -File build/dev-setup.ps1

# Обновить вендоренные скрипты uosc / thumbfast / autoload до свежих версий:
powershell -ExecutionPolicy Bypass -File build/vendor-scripts.ps1
```

Бинарник mpv в репозиторий не коммитится — он скачивается скриптами и лежит в
`build/vendor/` (в `.gitignore`). Конфиги, скин uosc и install-скрипты — в
репозитории. Публикация идёт в отдельный публичный репозиторий релизов, откуда
`DinaPlayer-Setup.exe` берёт сборки. Сторонние ассеты и лицензии — в
[`THIRD-PARTY.md`](THIRD-PARTY.md).

## Дизайнерам

Внешний вид (скин uosc и конфиги) кроссплатформенный — его можно править и смотреть на
macOS/Linux без Windows. Инструкция: [`docs/DESIGN.md`](docs/DESIGN.md).

## Приёмка (чек-лист)

Поставь свежую сборку через `DinaPlayer-Setup.exe` (или распакуй
`DinaPlayer-Portable.zip` и запусти `setup.bat`), затем проверь:

1. Правый клик по видео → «Play with DinaPlayer» → воспроизведение идёт.
2. Наведение на полосу перемотки → всплывают превью-миниатюры.
3. `Space` и клик по видео → пауза / воспроизведение (двойной клик — полный экран, без ложной паузы).
4. Меню uosc → переключение аудио-дорожки и субтитров.
5. Правый клик по папке с сериями → «Play with DinaPlayer» → плейлист в натуральном порядке (1, 2, …, 10).
6. Досмотреть серию до конца → автоматически стартует следующая.
7. Закрыть и открыть снова → продолжает с той же позиции и с теми же дорожками.

Управление намеренно минимальное; полная шпаргалка по горячим клавишам — в самом
плеере (меню ⚙ → «Keyboard shortcuts»).
